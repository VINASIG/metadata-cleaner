## Official facts checked

The [tool registry](tool-registry.md) contains the role-specific official URLs. Important corrections from current documentation:

- [Codex instructions](https://learn.chatgpt.com/docs/agent-configuration/agents-md), [skills](https://learn.chatgpt.com/docs/build-skills) and [MCP](https://learn.chatgpt.com/docs/extend/mcp?surface=cli) define discovery, precedence, the default combined 32 KiB budget and trusted project configuration. They do not define a Markdown `import` directive.
- [Playwright](https://playwright.dev/docs/intro) supports the three browser engines. [Accessibility testing](https://playwright.dev/docs/accessibility-testing) explains that automatic axe checks cover only part of accessibility.
- [Lighthouse agentic scoring](https://developer.chrome.com/docs/lighthouse/agentic-browsing/scoring) is experimental, requires the documented current Chrome capability, includes origin-trial WebMCP checks and does not replace a successful authorized task. Its score format is not the ordinary 0-100 Lighthouse performance score.
- [DevTools MCP](https://github.com/ChromeDevTools/chrome-devtools-mcp) has default usage statistics and optional CrUX requests. Its Lighthouse audit categories must be checked; use Lighthouse CLI for measured Performance runs rather than assuming a tool name includes them.
- [Motion AI Kit installation](https://motion.dev/docs/ai-kit-install) distinguishes free documentation/installer capabilities from Motion+ sign-in features including MotionScore. A marketing page and the installation guide described spring generation differently; account capability and the current installation guide take precedence. No premium access was tested.
- [Google's current AI optimization guide](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide) supports sound SEO and original useful content. It does not require llms.txt or special AI schema for its AI search surfaces.
- [Core Web Vitals](https://web.dev/articles/vitals) are field measurements at the 75th percentile: LCP at most 2.5 s, INP at most 200 ms and CLS at most 0.1. Lab TBT is not field INP.
- [HTML-validate presets](https://html-validate.org/rules/presets.html) document the Prettier compatibility preset. Only conflicting formatting rules are delegated; semantic validation remains active.
