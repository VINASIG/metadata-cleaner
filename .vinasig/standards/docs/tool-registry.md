## Icons and fonts

[Lucide](https://lucide.dev/guide/) 1.50.0 is the verified latest package family reference for UI icons; choose the appropriate framework package or selected SVGs rather than loading everything. The icon library uses ISC licensing. [Simple Icons](https://github.com/simple-icons/simple-icons) 16.33.0 supplies suitable third-party marks; the catalog's license does not grant trademark permission, and individual entries have their own guidance. These are consumer choices, not dependencies of this installer.

Space Grotesk is the user's settled UI typeface. The design system and Favicon Forge show local loading and bundled OFL notices. Font files are not redistributed in this standard. Test Vietnamese glyphs, supported weights, fallback and preload/base-path behavior in the actual consumer.

## Replacement policy

Choose by a missing capability, supported environment, repeatability, agent accessibility, privacy and maintenance cost. A tool called "agent-ready" is not automatically better than a demonstrated task flow. Record why a new tool replaces or extends the existing stack, pin it and rerun relevant fixtures. Do not install the entire registry.
