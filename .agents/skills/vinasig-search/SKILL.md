Check status, title/description, canonical, robots/noindex, sitemap, internal links, social metadata, actual HTML and truthful JSON-LD. Add hreflang checks only for multilingual pages. Validate source/output locally and inspect representative deployed URLs when permitted.

For a new public VINASIG website, launch, host/hosting change or DNS/sitemap/indexing repair, apply SEARCH-003 and read `templates/web/domain-discovery.md` inside the snapshot. Prepare concrete Cloudflare DNS and Search Console recommendations for missing setup, using the owner-provided dashboard links. Keep already-correct settings and healthy sitemap submissions. Observe live DNS/HTTPS/sitemap responses before proposing submission; separate local availability, submission, Google's fetch and confirmed page indexing. Account writes use existing authorization. Missing access is NOT_RUN with an actionable pending proposal.

Write useful sourced content that addresses real questions without fabricated claims. Current Google guidance governs Google eligibility; do not promise special AI files, schemas or wording guarantee citations. Preserve published URLs or provide a reviewed migration.

Use local tests/Lighthouse first, and a bounded crawler only when needed. External services, indexing submissions, analytics and crawler-policy changes need scope and account permission. Paid visibility tools are optional. Unavailable dashboards are NOT_RUN.

Report technical failures, content gaps and measured mentions/citations/referrals/conversions separately with platform, prompt sample, locale and date. No ranking or citation guarantee.
