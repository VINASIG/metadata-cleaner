# Brand adoption

The project adopts the established VINASIG Bright Playful Minimalism implementation from the adjacent tools, with the shared web-design-system chrome reviewed at f0fc7e5. Source artwork and font provenance/digests are in asset-manifest.json. The original Primary Color horizontal lockup is used on light surfaces and Reversed on dark surfaces before JavaScript runs. Logo links open https://vinasig.io.vn/. Source, issues and licenses are localized footer destinations.

Space Grotesk is served locally with its original OFL notice. Lucide supplies static interface icons. No new artwork, competing token library or OS picker is introduced. Metadata value panels use a platform monospace fallback for technical values. Shared header/footer CSS is byte-preserved and checked in builds and browser tests. The asset archive is read-only for this task.
