# License review

The new VINASIG application uses the already approved purpose-based defaults, AGPL-3.0-or-later for authored software and CC-BY-SA-4.0 for prose. Original font and logo rights remain separate. No historical contributor assignment or legal entity is invented. The initial application is new work with clearly identified copied VINASIG templates and retained grants.

ExifReader 4.46.0 is unmodified MPL-2.0 source. Its original license is distributed, and corresponding upstream source is identified at https://github.com/mattiasw/ExifReader and the exact npm package locked in package-lock.json. MPL-covered files retain their own rights. Lucide ISC, xmldom MIT, Astro MIT and font OFL notices are retained. Build-only tools remain governed by their own licenses. The full dependency lock is part of the corresponding source and preserves exact resolved package integrity.

Source and built license checks verify the grants, hash-preserved license texts, upstream notices and original assets. The deployed footer links to the exact source revision when built by CI. Account publication evidence and remaining rights review are distinct from local checks. Input images, their contents and generated image files do not inherit the application license.
