# Contribute

Read AGENTS.md and the product, research and toolchain records. Keep changes scoped, preserve existing work and keep both product languages complete. Technical source, documentation and commit messages use English.

Parser changes require primary container specifications and regression fixtures that exercise removed metadata, protected payloads, malformed structures and display behavior. Use synthetic files without real personal information. Never add file persistence, remote file loading or telemetry without product authorization. Treat file data as untrusted text; do not execute embedded content.

Run check, unit tests, build and relevant browser/performance checks. Open screenshots and inspect both header and footer. Never weaken an assertion, exclude an engine in CI or raise a budget to excuse a defect. Report unrun checks accurately. Publication and account changes follow task authorization.

Contributions retain authorship and use the applicable scope in LICENSES.md unless an accepted compatible grant is explicitly identified. Only submit material you have authority to license. Official brand assets remain separately governed.
